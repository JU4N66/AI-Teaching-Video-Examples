# 《苏州园林》AI 导入视频

> 面向初中语文课文叶圣陶《苏州园林》的 AI 视频课堂导入案例。

## 项目简介

本案例使用 AI 生成一段约 5–10 秒的江南园林意境短视频，用于课堂导入。视频通过纯视觉运镜带领学生进入园林，引导他们观察空间布局、层次与“图画美”，为后续课文学习铺垫。

[查看导入视频](./苏州园林导入.mp4)

## 教学目标

通过短视频创设情境，让学生直观感受苏州园林的：

- 园林空间层次
- 花窗与框景设计
- 亭台、假山、池水、花木之间的组合
- 中国古典园林的诗意与画意

视频也可帮助学生理解课文中“游览者无论站在哪个点上，眼前总是一幅完美的图画”的描述。

## 使用工具

- 即梦 AI：生成首帧图片与图生视频
- ChatGPT：协助梳理画面构思与提示词

## 制作流程

1. **确定教学场景**：围绕课文内容，选择纯视觉运镜而非数字人讲解，作为课堂情境导入。
2. **设计画面路径**：以“漏窗 → 园林深处 → 亭台、假山、池水、花木”为路径，突出空间层次与框景效果。
3. **生成首帧图片**：使用图片提示词生成具有江南古典园林特征的画面，并筛选构图、光线和建筑结构较稳定的版本。
4. **图生视频**：将选定的图片导入即梦 AI，使用视频提示词生成缓慢推进、穿过漏窗进入园林的镜头。
5. **筛选成片**：保留建筑结构稳定、运镜自然、园林意境贴合教学目标的版本。

## 提示词

### 图片生成 Prompt

```text
电影感写实风格+江南古典园林为主体+白墙黛瓦、花窗、曲廊、太湖石假山、池水与亭台组成层层递进的苏州园林空间+清晨柔和的阳光从树叶间洒落，薄雾轻盈+青绿、黛灰、米白色调，清雅宁静，具有中国画般的诗意+画面具有明显的空间层次与框景效果+电影级写实画面，无人物，无文字
```

### 视频生成 Prompt

```text
电影感写实风格+古典苏州园林为主体+镜头起始于一面白墙上的精致漏窗，窗外隐约可见亭台、假山、池水与花木，随着镜头靠近漏窗，园林景色逐渐清晰并形成一幅完整的画面+清晨柔和侧光，阳光穿过树叶形成自然光影，空气中有轻微薄雾+青绿、黛灰、米白色调，清雅、宁静、诗意，具有中国传统绘画意境+镜头从漏窗外缓慢向前推进，穿过漏窗逐渐进入园林内部，最后缓慢拉开空间展现亭台、假山、池水和花木的层次关系+树枝轻轻摇曳，池水微微荡漾，光影缓慢变化+5—8秒电影级写实视频，无人物，无数字人，无文字，无字幕，运镜平稳，园林建筑结构稳定
```

## AI 生成思路

这个案例的重点不是单纯生成一幅“漂亮的苏州园林”，而是让画面服务于语文教学。“漏窗框景”与“镜头推进”预先呈现园林的空间层次，让学生对园林布局和“图画美”形成直观感受，再进入文本学习。

## 课堂使用建议

播放视频后可暂不解释画面，先提问：

> 刚才的视频中，你觉得苏州园林最吸引你的是什么？

再追问：

> 为什么园林中的一扇窗，也能成为一幅画？

由此自然进入叶圣陶《苏州园林》的学习。
