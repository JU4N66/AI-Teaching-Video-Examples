# AI 教学视频示例

这个仓库记录如何把教学目标转化为 AI 视频：先用 Prompt 生成一张可控的关键画面，再以该图片为首帧进行图生视频，最后把成片用于课堂。

## 核心工作流

```text
教学文本与目标
        ↓
画面构思与 Prompt
        ↓
AI 生成首帧图片（筛选）
        ↓
图生视频 Prompt + 首帧图片
        ↓
筛选成片并设计课堂提问
```

## 如何复用这个方法

1. 从课文或教学主题中提炼一个明确的视觉目标，而不是笼统地要求“生成一个视频”。
2. 用图片 Prompt 先获得构图、主体、色调和氛围都符合预期的首帧图。
3. 在视频 Prompt 中明确镜头起点、运动方向、时长、环境动态和需要避免的内容。
4. 多次生成并筛选：优先选择主体结构稳定、运镜自然、画面真正支持教学目标的版本。
5. 为视频配套设计观察问题，让学生从观看过渡到学习内容。
